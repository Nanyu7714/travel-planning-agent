# 未实现功能清单

更新时间：2026-09-02

本文只记录当前代码没有完成、或需要外部服务才能完成的能力。已实现的基础页面和本地接口不在此重复列出。

## 用户端后续能力

| 功能 | 当前状态 | 后续工作 |
| :--- | :--- | :--- |
| 生产邮件投递配置 | 部分实现 | 邮箱验证、重发、找回密码、重置密码和新邮箱确认流程已完成；上线前仍需配置经过域名验证的 SMTP 服务及 SPF、DKIM、DMARC |
| AI 自然语言重新规划 | 部分实现 | 当前只支持本地解析天数、预算、删除和替换景点；需接入真实 LLM，并让模型输出结构化修改操作后再校验 |
| 实时热点排行 | 部分实现 | 当前热度由固定资料权重、收藏、最近浏览和对话提及组成；搜索点击埋点、周期统计和外部热点分析尚未接入 |
| 实时地图路线 | 未实现 | 接入高德等地图服务，保存路线缓存、调用失败降级和配额监控 |
| 真实图片资源 | 部分实现 | 已支持 Wikimedia 候选搜索、来源信息和后台审核；仍需接入对象存储、批量上传和生产级文件清理 |
| 反馈通知 | 部分实现 | 用户评分、评论和后台收件箱已可用；管理员通知、处理状态、回复和审计仍未实现 |

## 管理后台后续能力

- 城市、景点、图片和排行数据的新增、编辑、停用、批量导入及操作审计已经完成基础闭环；生产级数据审核和批量任务失败重试仍需完善。
- 反馈收件箱目前支持查看，尚未支持处理状态、管理员回复、分派和审计记录。
- 排行目前是请求时计算的启发式分数，尚未形成按季度固化的排行快照和趋势报表。

## 工程和上线工作

- 新增认证令牌、认证限流、行程修订、分享、反馈、最近浏览和用户偏好模型目前依靠应用启动兼容逻辑建表/补字段；正式 PostgreSQL 部署前需要补充 Alembic 迁移和回滚脚本。
- 需要继续补充前端端到端测试、Agent 多轮对话测试、并发编辑测试、分享链接撤销测试和生产故障演练。
- 真实 LLM、邮件、地图、图片和热点数据服务的密钥只能放在后端环境变量中，不能写入前端或提交到 Git。
