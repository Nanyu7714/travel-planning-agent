# 未实现功能清单

更新时间：2026-09-03

本文只记录当前代码没有完成、或需要外部服务才能完成的能力。已实现的基础页面和本地接口不在此重复列出。

## 用户端后续能力

| 功能 | 当前状态 | 后续工作 |
| :--- | :--- | :--- |
| 生产邮件投递配置 | 部分实现 | 认证邮件已使用 HTML 模板，并记录脱敏的投递状态、SMTP 尝试/重试次数、失败错误码和发送时间；上线前仍需配置经过域名验证的 SMTP 服务及 SPF、DKIM、DMARC，并按实际服务商补充异步重试与告警 |
| AI 自然语言重新规划 | 部分实现 | 已支持“分析-确认”流程：可选 LLM 只输出受 Schema 限制的操作，服务端再次校验；模型未配置或需求不完整时会要求澄清且不改动行程。复杂的每日时间、顺序、交通和住宿重排仍需专用规划能力 |
| 实时热点排行 | 部分实现 | 当前热度由固定资料权重、收藏、最近浏览和对话提及组成；搜索点击埋点、周期统计和外部热点分析尚未接入 |
| 跨城票务与站点接驳 | 部分实现 | 已支持选择出发城市，按出行日期查询高德往返跨城公共交通、打车或自驾路线，并将距离、耗时、费用计入完整预算；仍缺航班/火车票预订、座位余量、机场/车站到酒店的精确接驳、实时路况与配额监控 |
| 住宿与餐饮实时报价 | 部分实现 | 已按公开、固定的每人每日餐饮额度和每晚房间额度计入估算；仍需接入酒店和餐饮供应商数据，不能将当前估算当作实时预订价格 |
| 真实图片资源 | 部分实现 | 已支持 Wikimedia 候选搜索、来源信息和后台审核；仍需接入对象存储、批量上传和生产级文件清理 |
| 反馈通知 | 部分实现 | 用户评分、评论、后台分派、状态处理、回复和审计已可用；站内/邮件通知、SLA、批量分派和管理员内部备注仍未实现 |

## 管理后台后续能力

- 城市、景点、图片和排行数据的新增、编辑、停用、批量导入及操作审计已经完成基础闭环；生产级数据审核和批量任务失败重试仍需完善。
- 反馈收件箱已支持状态筛选、分派、管理员回复和审计记录；尚未支持处理通知、SLA、批量操作、内部备注和统计报表。
- 排行目前是请求时计算的启发式分数，尚未形成按季度固化的排行快照和趋势报表。

## 工程和上线工作

- 需要继续补充前端端到端测试、Agent 多轮对话测试、并发编辑测试、分享链接撤销测试和生产故障演练。
- 真实 LLM、邮件、地图、图片和热点数据服务的密钥只能放在后端环境变量中，不能写入前端或提交到 Git。
